Har naam ka object: { "n": "عائشہ", "e": "Aisha", "m": "زندہ رہنے والی، خوشحال", "g": "لڑکی" } n = Urdu naam, e = English spelling, m = Urdu matlab, g = sirf "لڑکا" ya "لڑکی" (bilkul isi tarah). App naamon ko Urdu order mein khud sort karti hai. Harf ka filter naam ke pehle harf se banta hai. NAYE NAAM JODNE KA TAREEQA: names.json ke edit link par jao, sab se neeche jao (aakhri line sirf "]" hoti hai). Us "]" ke BILKUL PEHLE tap karo. Pehli line mein sirf ek comma likho, phir nayi lines mein naye naam paste karo (aakhri naam ke baad comma nahi). Misaal paste: , { "n": "...", "e": "...", "m": "...", "g": "لڑکا" }, { "n": "...", "e": "...", "m": "...", "g": "لڑکی" } (b) data.json: { "names": { ... purana hissa, ab istemal nahi hota, ise rehne do ... }, "poetry": { "title": "شاعری", "icon": "✍️", "items": [ { "t": "unwan", "d": "matn" } ] }, "stories": { "title": "کہانیاں", "icon": "📚", "items": [ { "t": "unwan", "d": "matn" } ] }, "info": { "title": "اسلامی معلومات", "icon": "🕌", "items": [ { "t": "sawal", "d": "jawab" } ] } (ye hissa tabhi jab banaya ho) } t = title (fehrist mein), d = detail (poora matn). Nayi line ke liye \n, khali line ke liye \n\n. Jab tak "info" nahi banaya, "Islami Maloomat" ka card "jald aa raha hai" dikhata hai. (c) quotes.json = Urdu jumlon ka array: [ "پہلی بات", "دوسری بات", "تیسری بات" ] Home par roz ek baat dikhti hai (din ke hisaab se: din ka number % baaton ki ginti). Agar quotes.json load na ho to index.html ki apni 7 purani baatein dikhti hain. (d) manifest.json (maujooda): name "Meri Islamic App", short_name "Islamic App", start_url "./index.html", scope "./", display "standalone", background_color "#f3f7f4", theme_color "#0f6b4a", lang "ur", dir "rtl", icons: icon-192.png (192x192), icon-512.png (512x512). (e) sw.js (maujooda ya jo bhi file mein ho; kuch badalne se pehle meri sw.js dekh lo): - CACHE ka naam "islamic-app-vN" (jaise v4). - FILES list: "./", "./index.html", "./data.json", "./names.json", "./manifest.json", "./icon-192.png", "./icon-512.png". - Fetch: pehle internet se laata hai (network-first), kamyab ho to cache mein rakhta hai, nakam ho to cache se deta hai. - Jab koi NAYI FILE app mein jodi jaye to uska naam FILES mein jodo aur CACHE ka number ek barha do. - Sirf naam/shayari/quotes badalne par version barhana zaroori nahi. JSON KE 5 QAIDE (har baar dhyan rakho) 1. Do cheezon ke beech comma, aakhri cheez ke baad nahi. 2. Har likhai double quotes " " ke andar. 3. Likhai ke andar seedha " na ho (uski jagah ' ya « » istemal karo). 4. Nayi line ke liye \n, khali line ke liye \n\n. 5. Har { [ ka } ] zaroor ho. 2.5 INDEX.HTML KA ANDRUNI NAQSHA (taake AI samjhe ke file kaise bani hai) - Ek hi file: HTML + CSS + JS. - : manifest link, theme-color, Google Fonts (Noto Nastaliq Urdu), CSS.
